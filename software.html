TriageIA — Priorización Médica Automática

Sistema de soporte a la decisión clínica que transforma el relato del paciente en una prioridad Manchester (C1–C5) mediante modelos NLP entrenados localmente. Pipeline orquestado con Apache Airflow, almacenamiento en MinIO y exposición de inferencia vía FastAPI con dashboard Streamlit.

AirflowFastAPI StreamlitspaCy scikit-learnMinIO PostgreSQLDocker

Nexus — Mensajería en tiempo real

Aplicación de mensajería full stack: SPA en React y TypeScript (Zustand, reconexión con backoff exponencial) sobre un backend en Go con API REST y WebSockets. Escalado horizontal con Redis Pub/Sub, búsqueda full-text en PostgreSQL, JWT y observabilidad con Prometheus y OpenTelemetry.

GoReactTypeScriptWebSocketsRedisPostgreSQLDocker
GitHub

QuickBuy — E-commerce con microservicios

7 microservicios en Java 21 y Spring Boot (API Gateway, Eureka, Config Server) coordinados con Apache Kafka: coreografía Saga, patrón Outbox y CQRS con PostgreSQL y Redis. Frontend en React 19 con panel de administración y trazas con Zipkin, Prometheus y Grafana.

Java 21Spring BootKafkaPostgreSQLRedisReactDocker
